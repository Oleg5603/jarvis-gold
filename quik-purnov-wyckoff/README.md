# Индикаторы Пурнова и Вайкоффа для QUIK

Архив исходников, собранный 28 сентября 2026 года.

- `installed/` — пять файлов, найденных в активной папке `C:\QuikFinam\LuaIndicators` на момент копирования.
- `archive/quik-backups/` — 20 сохранённых резервных версий из QUIK.
- `experimental/` — варианты из рабочих папок Codex и заметки. Это архив разработки: названия ready/final/staging не подтверждают успешную проверку в QUIK. Сюда включены и копии индикаторов из других сборок.
- `purnov-indicator/` — исходный проект Пурнова, его тесты, настройки и торговая лаборатория.
- `MANIFEST.json` — список исходных файлов, размеры, SHA-256 и Git blob SHA-1 для точной проверки скачанной версии.

## Установка

Сначала сохраните резервную копию своей папки LuaIndicators. Для воспроизведения установленного набора используйте только `installed/`. Архивные и экспериментальные файлы не устанавливаются автоматически.

`WyckoffClearChartLabels.lua` — вспомогательный скрипт очистки меток, а не торговый индикатор.

Наличие файла в `installed/` означает только его присутствие в папке QUIK. Эта публикация не подтверждает визуальную приёмку графиков, корректность торговых сигналов или результаты исследования. Исследования и автоматическая торговля при публикации не запускались.

Файлы сохранены без изменения исходной кодировки и содержимого. Кэш Python, временные файлы тестов, зависимости и журналы не включены. Медиауроки и их полные расшифровки не входят в этот архив индикаторов.
