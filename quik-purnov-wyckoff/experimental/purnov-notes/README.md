# Purnov Context Signals для QUIK

## Версия 3.0

`PurnovContextV3.lua` добавляет две расчётные объёмные зоны, отдельную линию
подтверждённой цели и фильтр старшего контекста. Старший контекст — это
расчётный фильтр на текущем графике; для фактического H4 добавьте этот же
индикатор на H4-график инструмента и не подтверждайте вход, пока направления
не совпадут. Объёмные зоны — приближение по свечному объёму, а не замена
ручному Volume Profile. Линия цели появляется только когда достигнут R/R 1:3.

Индикатор-подсказчик объединяет идеи из структуры курсов Александра Пурнова: контекст, уровни, побарный анализ, VSA-сигналы и подтверждение объёмом.

## Установка

1. Скопируйте `PurnovContextV3.lua` в папку индикаторов QUIK (`LuaIndicators`). Предыдущие версии сохранены отдельно для сравнения.
2. Перезапустите QUIK или обновите список индикаторов.
3. Добавьте `Purnov Context Signals v2` на свечной график с объёмом.
4. Начните с периода 30; параметры подбирайте отдельно для инструмента и таймфрейма.

## Что показывает

- синяя линия снизу — поддержка за выбранный период;
- синяя линия сверху — сопротивление;
- зелёная/красная точка — сетап готов, но подтверждения входа ещё нет;
- зелёный/красный треугольник — подтверждённый BUY/SELL-кандидат;
- первая гистограмма — этап чек-листа: зона (`1`) или ослабление (`2`);
- вторая гистограмма — расчётное отношение риск/прибыль.

Разворот проходит `зона → ослабление противоположной стороны → появление своей стороны`. Пробой проходит `JOC/SOW → возвратный тест BTC/BTI`. Стрелка разрешается только при расчётном отношении риск/прибыль не ниже `3.0`. `ExplainSignal(index)` возвращает этап и причины.

## Важно

- Решение принимается только после закрытия сигнальной свечи. Метка выводится на следующем баре и не зависит от его меняющихся OHLCV.
- Индикатор не открывает сделки и не гарантирует доходность.
- Стоп рассчитывается за зоной и «уровнем неправоты» сигнального бара; размер позиции нужно считать отдельно.
- Индикатор не разрешает доливку и не управляет позицией: это отдельный модуль после проверки входов.
- Перед реальной торговлей обязательны визуальная проверка и тест минимум на 200 исторических сигналах без подгонки параметров.
- Комиссии, проскальзывание, гэпы и ликвидность в расчёт не входят.

## Код причины

Положительная гистограмма означает BUY, отрицательная — SELL. Сила 3: минимально допустимое совпадение; сила 4: сигнал + объём + согласованный контекст. Цветной треугольник — подсказка для анализа, не торговая команда.
