# Purnov Effort-Result Context — v2.0

Индикатор контекста для QUIK (QLua), собранный по темам архива Пурнова:
уровни, Spring/Upthrust, JOC/SOW, объём и направление контекста.

## Что показывает

- динамические поддержку и сопротивление по предыдущим барам;
- зелёную метку после подтверждённого Spring или JOC;
- красную метку после подтверждённого Upthrust или SOW;
- сигнал только по закрытому бару, без чтения будущих свечей.
- сопоставление усилия (относительного объёма) и результата движения;
- обязательную предшествующую активность в зоне сигнала;
- отказ от сигнала, когда большой объём не дал достаточного результата.

Индикатор не открывает сделки. Это фильтр кандидатов для визуальной проверки,
а не торговая рекомендация или гарантия результата.

## Где установлен

`C:\QUIK_SBER\LuaIndicators\PurnovEffortResult_v2.lua`

Исходник проекта: `PurnovContext.lua` в этой папке; установленная копия имеет
отдельное имя `PurnovEffortResult_v2.lua`, чтобы не смешиваться с прежней версией.

Правила будущей расшифровки и экономии токенов закреплены в
`TRANSCRIPTION_PROTOCOL.md`; машинные ограничения — в `pipeline/config.json`.

## Подключение в QUIK

1. Перезапустить QUIK либо обновить список индикаторов.
2. Открыть график инструмента.
3. Добавить индикатор `Purnov Context Signals MVP`.
4. Начать с параметров по умолчанию и проверить не менее 200 исторических
   сигналов с учётом комиссии и проскальзывания.

## Параметры

- `period = 20` — окно уровней и среднего объёма;
- `trend_period = 34` — окно контекста;
- `volume_factor = 1.35` — повышенный объём;
- `result_min = 0.55` — минимальный прогресс относительно среднего диапазона;
- `close_location = 0.65` — закрытие в направленной части диапазона;
- `activity_lookback = 8` — окно поиска предшествующей активности;
- `wick_factor = 1.20` — минимальное отношение хвоста к телу;
- `atr_buffer = 0.15` — подтверждение выхода за уровень в долях ATR;
- `min_score = 3` — минимальная сумма подтверждений.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Проверка контролирует контракт QLua, четыре ценовые линии и отсутствие
обращений к будущим барам в расчёте сигнала.
