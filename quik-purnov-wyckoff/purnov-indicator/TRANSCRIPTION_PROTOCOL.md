# Экономный протокол расшифровки архива Пурнова

Статус: принят как обязательный для всех будущих запусков.

## Жёсткие правила

1. Аудио и первичный текст обрабатываются локально через `faster-whisper`.
   Полные видео и полные транскрипты не отправляются в LLM.
2. Работа возобновляется с приоритетной выборки уроков, а не со всех 175 часов.
3. Каждый результат сохраняется на диск сразу после этапа; повторная обработка
   готового файла запрещена без явного `--force`.
4. Реклама, приветствия, технические паузы, повторы и организационные блоки
   помечаются как шум и не попадают в контекст модели.
5. LLM получает только найденные релевантные фрагменты и карточки знаний.
   Лимит одного запроса: 8 фрагментов и 10 000 входных токенов.
6. Любое торговое правило должно иметь ссылку на источник: файл и таймкод.
7. Неясные или противоречивые правила помечаются `needs_review`; модель не
   должна превращать их в уверенный сигнал индикатора.

## Приоритет первой очереди

1. Контекст рынка и фазы.
2. Уровни и уровень неправоты.
3. Spring и Upthrust.
4. JOC, BTC, SOW, LPS/LPSY.
5. Объём, дельта и захват ликвидности.
6. Сопровождение позиции и выход.

## Артефакты одного урока

```text
transcripts/raw/<id>.json       сегменты Whisper с таймкодами
transcripts/clean/<id>.md       очищенный текст
knowledge/cards/<id>.json       структурированная карточка
knowledge/index.jsonl           локальный поисковый индекс
state/manifest.json             статус и хэши входных файлов
```

Карточка урока содержит:

```json
{
  "topic": "",
  "source_file": "",
  "time_ranges": [],
  "market_context": [],
  "entry_rules": [],
  "confirmations": [],
  "invalidation": [],
  "exit_rules": [],
  "exceptions": [],
  "examples": [],
  "confidence": "low|medium|high",
  "status": "draft|verified|needs_review"
}
```

## Иерархическое сжатие

```text
видео → локальный транскрипт → очищенные фрагменты → карточка урока
      → сводка темы → проверенные правила индикатора
```

Полный транскрипт остаётся локальным доказательным слоем. В рабочий запрос
передаются карточка темы и 3–8 исходных фрагментов, найденных индексом.

## Контроль качества

- минимум два независимых примера для правила;
- негативный пример или исключение обязательно;
- дословность проверяется по таймкоду;
- правила индикатора не принимаются только по названию файла/урока;
- перед автоматизацией — ручная проверка и исторический тест минимум на 200
  сигналов с комиссией и проскальзыванием.

## Бюджет

- Whisper локально: 0 LLM-токенов;
- очистка регулярными правилами: 0 LLM-токенов;
- поиск по локальному индексу: 0 LLM-токенов;
- LLM: только карточки и релевантные цитаты, не более 10 000 входных токенов
  на один аналитический запрос.
