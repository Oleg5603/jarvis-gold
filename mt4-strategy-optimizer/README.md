# MT4 Strategy Optimizer — MVP

Отдельное Windows-приложение для подготовки и оптимизации параметров советников MT4.

## Запуск

Дважды щёлкните `Запустить MT4 Оптимизатор.bat`.

Сейчас приложение:

- находит установленный MT4;
- выбирает советник `.ex4` и пресет `.set`;
- редактирует значения и диапазоны оптимизации;
- сохраняет воспроизводимый manifest с SHA-256;
- экспортирует `.set` с резервной копией существующего файла.

Автоматический запуск Strategy Tester, расчёт Score и Forward/Stability входят в
следующий этап разработки.
