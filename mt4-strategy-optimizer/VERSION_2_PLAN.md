# EA Optimizer Lab 2.0 — план создания

## Решение о готовности 1.0

Версия 1.0 пока **не готова к финальному релизу**. Текущий статус: рабочий
MT4-MVP / beta.

Готово и проверено:

- запуск изолированного MT4 Strategy Tester;
- чтение `.set`, диапазоны, штатная генетическая оптимизация MT4;
- реальный прогон на 5132 варианта и чтение HTML-отчёта;
- рейтинг, TOP, Forward, Stability, история SQLite и экспорт `.set`;
- расписание, индикатор выполнения и сохранение настроек;
- backup-first при экспорте; 16 автоматических тестов проходят.

До релиза 1.0 обязательно закрыть:

- проверку полного цикла `Train -> TOP -> Forward -> Stability -> лучший .set`
  на двух разных советниках;
- пользовательские ограничения комбинаций без жёстко заданного правила для всех EA;
- восстановление незавершённой очереди после перезапуска приложения/ПК;
- точный прогресс: завершено/всего проходов, а не бесконечная анимация;
- проверку расписания реальным автоматическим запуском;
- безопасную установку выбранного `.set` и проверенный rollback;
- понятное объяснение массовых `initialization failed` и их учёт в результате;
- обновление README и маркировку сборки `1.0`.

## Цель 2.0

Локальная лаборатория развития советников:

```text
Советники с открытых графиков
  -> последовательная очередь тестов
  -> оптимизация и TOP-N
  -> Forward / Walk Forward / Stability / Monte Carlo
  -> AI-гипотеза
  -> подтверждение пользователя
  -> ограниченный патч MQL4
  -> компиляция и повторный цикл
  -> Champion / Challenger
  -> подтверждаемая установка .set на выбранный график
```

Лаборатория не открывает сделки и не включает AutoTrading.

## Основные сценарии

### 1. Советники с открытых графиков

Кнопка `Найти советники на графиках` сканирует активный профиль MT4 и показывает:

- советник и путь к `.ex4/.mq4`;
- символ и таймфрейм;
- имя графика/профиля;
- текущие input-параметры;
- статус: доступен, дубликат, файл не найден, Market-защита.

Первая реализация читает копии файлов активного профиля `.chr`. Сканер работает
только с копией и ничего в профиле не меняет. Перед запуском пользователь отмечает
галочками нужные графики. Для несовместимого `.chr` остаётся ручной выбор EA.

### 2. Последовательное автотестирование

Пользователь формирует очередь:

```text
1. MA2MA / XAUUSD / M1
2. Sniper3 / XAUUSD / M15
3. AnotherEA / EURUSD / H1
```

Для каждого задания выполняются Train, отбор TOP-N, Forward и Stability. Следующее
задание начинается только после завершения предыдущего. Очередь хранится в SQLite,
имеет `pending/running/paused/failed/completed` и продолжается после сбоя. Доступны
`Старт`, `Пауза после текущего`, `Пропустить`, `Повторить`, `Остановить`.

### 3. Выбор числа лучших вариантов

Настройка `Показывать лучших`:

- быстрые значения: 5, 10, 20, 50;
- произвольное число: 1–200;
- отдельное значение `Отправлять в Forward`: не больше показанного TOP-N;
- hard gates: минимум сделок, максимум DD, минимум PF;
- результаты с бесконечным/невалидным Score не попадают в рейтинг.

### 4. Установка `.set` на график

Никогда не выполняется автоматически. После выбора результата программа показывает
диалог:

```text
Установить набор на график?
EA: MA2MA
График: XAUUSD M1
Текущий set: ...
Новый set: ...
Train / Forward / Stability: ...
[Сравнить] [Установить] [Отмена]
```

При установке обязательно:

1. проверить точное совпадение EA, символа и TF;
2. сохранить `.set`, `.chr/.tpl` и manifest в backup;
3. запретить действие во время теста и при неизвестном состоянии терминала;
4. применить параметры через подготовленный шаблон MT4;
5. проверить повторным чтением профиля;
6. показать `Успешно` либо выполнить rollback;
7. записать действие в audit log.

Если безопасное применение к открытому графику не подтверждено интеграционным
тестом, версия 2.0 только сохраняет `.set` и открывает инструкцию загрузки в MT4.

## Этапы разработки

### E0 — Release gate 1.0

Закрыть перечисленные выше долги. Зафиксировать два реальных эталонных отчёта и
smoke-тест полного цикла. Результат: стабильная база, на которой строится 2.0.

### E1 — Проекты и очередь

- сущности `Project`, `ChartTarget`, `BatchJob`, `Run`, `Candidate`, `Artifact`;
- миграции SQLite;
- последовательный coordinator с resume;
- выбор TOP-N и Forward-N;
- экран очереди и точный прогресс.

### E2 — Обнаружение открытых графиков

- поиск data folder и активного profile;
- read-only парсер `.chr` с versioned fixtures;
- дедупликация одинаковых EA/символ/TF;
- ручное подтверждение найденного списка;
- fallback на обычный выбор `.ex4/.set`.

### E3 — Проверки качества

- опциональные правила конкретного советника; глобального правила
  `FAST < MID < SLOW` нет;
- Train/Forward без утечки данных;
- Walk Forward с настраиваемыми окнами;
- Stability plateau score;
- Monte Carlo по сделкам, spread, slippage и пропускам;
- месяцы/годы, BUY/SELL, часы, recovery и Sharpe.

### E4 — Champion / Challenger

- BASE только для чтения;
- версии `v001...vNNN` и неизменяемые artifacts;
- сравнение с Champion по одинаковому manifest;
- PASS/FAIL gates;
- ручное назначение нового Champion;
- архив и полный журнал экспериментов.

### E5 — AI-гипотезы в SEMI-AUTO

- AI получает сделки и агрегаты без ключей/счёта;
- сначала создаёт гипотезу, ожидаемый эффект и риски;
- пользователь разрешает или отклоняет эксперимент;
- изменения только в разрешённых зонах ENTRY/EXIT;
- максимум три попытки исправления компиляции;
- отдельный Risk Agent пытается отклонить Challenger;
- вывод AI не может переопределить численные gates.

### E6 — Установка результата

- comparison dialog и явное подтверждение;
- backup/atomic apply/verification/rollback;
- сначала тестовый portable MT4;
- рабочий MT4 допускается только после отдельной приёмки и предупреждения;
- никакого включения AutoTrading и никаких торговых операций.

## Агенты 2.0

- `Run Coordinator` — очередь, возобновление, таймауты;
- `MT4 Adapter` — профили, tester config, запуск и отчёты;
- `Statistician` — Score, Walk Forward, Stability, Monte Carlo;
- `Analysis Agent` — причины убытков и гипотезы;
- `Coding Agent` — только разрешённые MQL4-зоны;
- `Compiler Agent` — MetaEditor и ограниченные исправления;
- `Risk Agent` — независимая попытка забраковать результат;
- `Deployment Guard` — подтверждение, backup, установка и rollback.

LLM-провайдеры сменные. Полный тестовый цикл работает в режиме `NoAI`.

## Приёмка 2.0

1. Сканер находит EA/символ/TF минимум в трёх реальных открытых графиках.
2. Ошибочный или неизвестный `.chr` не изменяется и не роняет приложение.
3. Очередь из трёх EA выполняется строго последовательно.
4. Перезапуск приложения продолжает незавершённую очередь без дублей.
5. TOP-N принимает 1–200 и сохраняется в проекте.
6. Forward видит только замороженных Train-финалистов.
7. Комбинации блокируются только правилами, явно заданными для выбранного EA.
8. Walk Forward, Stability и Monte Carlo воспроизводимы по manifest/seed.
9. AI не может принять Challenger при проваленном hard gate.
10. BASE и Champion никогда не перезаписываются без новой версии и backup.
11. Установка `.set` всегда требует отдельного подтверждения.
12. Отмена диалога не меняет ни профиль, ни график, ни `.set`.
13. Ошибка применения восстанавливает исходный профиль побайтно.
14. Приложение не вызывает торговые функции и не включает AutoTrading.

## Рекомендуемый порядок релизов

- `1.0`: надёжный одиночный цикл готового EA;
- `1.1`: очередь, TOP-N, resume, обнаружение графиков;
- `1.2`: Walk Forward и Monte Carlo;
- `2.0-beta`: Champion/Challenger и AI-гипотезы;
- `2.0`: ограниченное изменение MQL4 и подтверждаемая установка на график.

## Подтверждённые решения

Подтверждено пользователем 2026-08-23:

1. сканировать только активный профиль MT4;
2. объединять одинаковые `EA + символ + TF` в одно тестовое задание;
3. показывать TOP-20 по умолчанию, оставив выбор 1–200;
4. сначала устанавливать `.set` только на график тестового portable MT4;
5. перед каждой установкой обязательно спрашивать подтверждение пользователя;
6. AI-изменение `.mq4` отложить до 2.0-beta; ранние этапы создают только
   проверяемые гипотезы.
