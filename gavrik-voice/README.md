# Гаврик Голос

Локальный голосовой помощник для Windows. Он не хранит голосовые записи и не
отправляет сообщения сам.

## Запуск

Дважды щёлкните `start_gavrik_voice.bat`.

## Примеры команд

- «Открой браузер»
- «Открой Телеграм»
- «Найди договор в интернете»
- «Найди файл договор»
- «Покажи рабочий стол»
- «Напиши перезвони мне вечером»

## Безопасность

Программа всегда показывает распознанную фразу и действие до выполнения.
Закрытие окна требует отдельного подтверждения. Сообщения только копируются в
буфер обмена: пользователь сам выбирает адресата и нажимает «Отправить».

Если голос не распознаётся, проверьте разрешение Windows на микрофон и наличие
русского пакета распознавания речи. Команду можно напечатать в строке ввода.
